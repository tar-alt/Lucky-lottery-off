# Lucky Lottery - 1 Min Win Go Game System

## Features
- Real-time Win Go (1 Min) Server-side Engine.
- User Authentication & Unique Player ID Generator.
- Admin Panel (`/admin.html`) for Direct Unit Transfers & Tx Approval.
- SQLite Database & Express Socket.io integration.

## Deploying to Render
1. Push this repository to GitHub.
2. Go to Render.com -> Create New **Web Service**.
3. Build Command: `npm install`
4. Start Command: `npm start`
